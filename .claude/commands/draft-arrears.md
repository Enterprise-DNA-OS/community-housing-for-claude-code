# /draft-arrears

The draft goes to drafts/. It is not a formal notice. Show it and say what the housing officer should check.

```bash
node scripts/housing.mjs draft-arrears <tenancy>
```

Use the configured database. Add `--json` when structured output helps. If a name is ambiguous, list the candidates and ask. Never guess a record and never send a message.
